# Anikura CN 自动签到

在 [anikura.cn](https://www.anikura.cn) 上自动完成每日签到，提供两个版本：

| 版本 | 文件 | 触发方式 | 适用场景 |
| --- | --- | --- | --- |
| 油猴脚本（推荐） | [anikura-auto-checkin.user.js](anikura-auto-checkin.user.js) | 打开 anikura.cn 任意页面时自动签到 | 你本来就会打开网站 |
| Chrome 插件 | [extension/](extension/) | Chrome 运行时每小时检查一次，每天自动签到 | 想彻底不用打开网站页面，只要 Chrome 在跑就行 |

## 工作原理（简单版）

网站登录后会把登录状态存在浏览器的 cookie 里（Supabase session）。签到本身调用的是网站的
`perform_checkin` 接口。脚本读取你浏览器里已有的登录态，代为调用同一个接口，和你在页面上点
“立即签到”完全等价：

- 每次签到随机获得 5–20 积分，连续 7 天额外 +10（网站规则）；
- 一天只能成功一次，重复调用会返回“已签到”，不会重复加分，所以脚本每天最多签一次；
- 脚本**不会**收集或上传任何数据，账号密码不会经过脚本，登录态只在本机浏览器内使用。

## 一、油猴脚本（Tampermonkey）

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展；
2. 点击 Tampermonkey 图标 → “添加新脚本”，把
   [anikura-auto-checkin.user.js](anikura-auto-checkin.user.js) 的全部内容粘贴进去并保存；
3. **先手动登录一次 anikura.cn**（登录一次后登录态会保留在浏览器里）；
4. 之后每次打开 anikura.cn 任意页面，脚本会在右下角提示签到结果。

附加功能：

- Tampermonkey 菜单里有“立即签到（手动触发）”，可随时手动签一次；
- 签到成功时会弹出一条系统通知（可选）。

## 二、Chrome 插件版

1. 打开 `chrome://extensions/`，右上角开启“开发者模式”；
2. 点击“加载已解压的扩展程序”，选择本目录下的 `extension` 文件夹；
3. **先手动登录一次 anikura.cn**；
4. 之后只要 Chrome 在运行，插件会每小时检查一次，每天自动签到一次（不需要打开 anikura 页面）。

签到成功或失败都会通过系统通知提醒（成功、失败每天各最多一条，点击通知会直接打开签到页）；
如果不想要通知，在插件弹窗里取消勾选“启用签到结果通知”即可。点击插件图标可看到最近一次
签到结果，也可以手动“立即签到”。

## 注意事项

- 两种方案都要求浏览器在运行：插件只需 Chrome 开着，油猴脚本需要打开 anikura.cn 页面。
- 如果很久没登录、登录态过期，插件会自动用 refresh_token 刷新；油猴脚本依赖页面自己刷新，
  失败时会在右下角提示，你打开一次网站即可。
- 如果被登出（或修改了密码），需要重新登录一次 anikura.cn。
- 网站改版导致接口变化时，脚本可能需要更新。当前版本基于 2026-08 抓取的网站代码。

## 可选：完全脱离浏览器（服务器定时任务）

如果希望“电脑/浏览器完全不用开也能每天自动签到”（例如跑在自己的服务器或 GitHub Actions
上），需要提供 anikura.cn 的邮箱和密码（用于调用 Supabase 登录接口换取登录态），并自行部署
一个 Python/Node 定时任务。本仓库目前只提供浏览器内运行的版本。
